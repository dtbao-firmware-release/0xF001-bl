# 0xF001

Release channel for the ESP32-S3 RS-485 isolated gateway firmware (product id `0xF001`).

Each release carries the encrypted application image, `bl_*_enc.bin`, built and published
by the release workflow of the firmware repository. The tag matches the firmware version.

The source, build instructions and the full set of artefacts (bootloader, partition table,
`.elf`, checksums) live in the firmware repository, not here.
